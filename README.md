# نرم‌افزار حسابداری سپهر (Sepehr Accounting ERP)

نرم‌افزار حسابداری و بازرگانی سپهر، یک سامانه جامع، حرفه‌ای و تمام‌عیار برای مدیریت حسابداری دوطرفه (دوبل)، انبارداری چندمرحله‌ای، صدور فاکتور و فاکتور فوری (POS)، خزانه‌داری (صندوق، بانک، چک صیادی) و گزارش‌های پیشرفته مالی برای اصناف بازرگانی و فروشگاهی است.

---

## ۱. ویژگی‌های کلیدی سامانه
- **حسابداری دوطرفه استاندارد (Double-Entry Bookkeeping):** ثبت و تراز خودکار کلیه رویدادهای مالی، دفاتر کل، معین، روزنامه و تراز آزمایشی ۴ و ۶ ستونی.
- **واحد رسمی پول «ریال»:** پشتیبانی کامل از واحد ریال و تبدیل خودکار ارقام فارسی.
- **سیستم راه‌اندازی گام به گام (Onboarding Wizard):** راه‌اندازی سریع اولیه مشخصات فروشگاه، سال مالی و موجودی افتتاحیه.
- **صفر کردن برنامه (Factory Reset):** پاکسازی کامل اطلاعات آزمایشی و آماده‌سازی سیستم جهت تحویل به مشتری با امنیت بالا.
- **سیستم به‌روزرسانی آنلاین از گیت‌هاب (Online Auto-Update):** دریافت تغییرات جدید از گیت‌هاب، پشتیبان‌گیری خودکار، نصب وابستگی‌ها و بیلد مجدد بدون نیاز به بستن دستی برنامه.
- **راه‌اندازی در پس‌زمینه ویندوز بدون پنجره سیاه (Silent Daemon):** اجرای مخفی و پایدار با `run_hidden.vbs` و حلقه راه‌اندازی مجدد در `start_server.bat`.

---

## ۲. راه‌اندازی و اجرای نرم‌افزار

### در ویندوز (روش‌های اجرا):
1. **اجرای مخفی در پس‌زمینه (توصیه‌شده):**
   - روی فایل `run_hidden.vbs` دابل کلیک کنید. سرور به صورت کاملاً مخفی و بدون باز شدن پنجره سیاه CMD اجرا می‌شود.
2. **اجرا با پنجره وضعیت سرور:**
   - روی فایل `start_server.bat` دابل کلیک کنید.
3. **اجرای خودکار با روشن شدن ویندوز (Windows Startup):**
   - کلیدهای `Win + R` را فشرده و دستور `shell:startup` را تایپ و اجرا کنید.
   - یک میانبر (Shortcut) از فایل `run_hidden.vbs` ساخته و در پوشه بازشده قرار دهید.

آدرس دسترسی در مرورگر: **`http://localhost:3000`**

---

## ۳. به‌روزرسانی آنلاین (Online Auto-Update)
- **از داخل برنامه:** با رفتن به منوی **تنظیمات > به‌روزرسانی آنلاین**، با یک کلیک آخرین نسخه از مخزن گیت‌هاب دریافت، دیتابیس پشتیبان‌گیری و سرور ظرف چند ثانیه با کدهای جدید راه‌اندازی می‌شود.
- **به‌صورت دستی:** با اجرای اسکریپت `update.bat` در ویندوز یا `update.sh` در مک و لینوکس.

---

## ۴. دستورات خط فرمان توسعه (Development Scripts)

```bash
# نصب وابستگی‌ها
npm install

# اجرای حالت توسعه
npm run dev

# اجرای سرور پروداکشن
npm run start

# بیلد نهایی پروژه
npm run build

# اجرای آزمون‌های جامع (۷۷ تست واحد و یکپارچه)
npm test

# بررسی تایپ‌های تایپ‌اسکریپت
npm run lint
```
